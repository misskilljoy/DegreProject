# Админка Degre Design

Адрес после публикации: `https://degredesign.ru/admin/`.

## Подключение безопасного входа

1. Создать проект в Supabase.
2. В **Authentication → Users** создать и подтвердить пользователя `erzhenchik24@gmail.com`. В форме админки для него используется короткий логин `zhenijoy`.
3. В **Authentication → Sign In / Providers → Email** оставить Email включённым и отключить самостоятельную регистрацию новых пользователей.
4. В **Authentication → URL Configuration** указать Site URL `https://degredesign.ru` и добавить Redirect URL `https://degredesign.ru/admin/`. Это необходимо для безопасного восстановления пароля по почте.
5. В **SQL Editor** выполнить `supabase/schema.sql`. Политики записи привязаны к UID созданного администратора `eda34486-95b6-46f6-9465-ba5404e5dace`, а не только к его e-mail.
6. В **Project Settings → API** скопировать Project URL и публичный `Publishable key` (в старом интерфейсе — `anon` key).
7. В `scripts/cms-config.js` заполнить `supabaseUrl` и `anonKey`. Публичный ключ предназначен для браузера; права ограничивает RLS из `schema.sql`. Secret key и service-role key на сайт добавлять нельзя.
8. Войти в `/admin/` и нажать **«Импортировать текущие проекты»**.

После этого проекты, обложки, планировки и галереи управляются из админки. Сайт читает опубликованные записи из Supabase, а при недоступности сервиса использует текущие данные из `scripts/project-data.js`.

Для рабочего аккаунта следует установить новый уникальный пароль длиной от 16 символов и включить MFA в Supabase. Пароль локального деморежима нельзя повторно использовать в рабочем аккаунте. Кнопка **«Забыли пароль?»** отправляет письмо на `erzhenchik24@gmail.com`; ссылка из письма открывает форму установки нового пароля в админке.

## Локальная проверка

На `localhost` без Supabase работает деморежим с логином `zhenijoy` и согласованным с владельцем паролем. В коде хранится только SHA-256-хеш пароля. Деморежим сохраняет изменения только в Local Storage браузера и никогда не включается на домене сайта.
