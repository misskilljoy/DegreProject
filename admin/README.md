# Админка Degre Design

Адрес после публикации: `https://degredesign.ru/admin/`.

## Подключение безопасного входа

1. Создать проект в Supabase.
2. В **SQL Editor** выполнить `supabase/schema.sql`.
3. В **Authentication → Users** создать пользователя `zhenijoy@degre.local` с паролем, согласованным с владельцем сайта. В админке вводится короткий логин `zhenijoy`; доменная часть добавляется автоматически. Самостоятельную регистрацию посетителей не включать.
4. В **Project Settings → API** скопировать Project URL и публичный `anon` key.
5. В `scripts/cms-config.js` заполнить `supabaseUrl` и `anonKey`. Публичный anon key предназначен для браузера; права ограничивает RLS из `schema.sql`. Service-role key на сайт добавлять нельзя.
6. Войти в `/admin/` и нажать **«Импортировать текущие проекты»**.

После этого проекты, обложки, планировки и галереи управляются из админки. Сайт читает опубликованные записи из Supabase, а при недоступности сервиса использует текущие данные из `scripts/project-data.js`.

Для рабочего аккаунта следует установить новый уникальный пароль длиной от 16 символов и включить MFA в Supabase. Пароль локального деморежима нельзя повторно использовать в рабочем аккаунте.

## Локальная проверка

На `localhost` без Supabase работает деморежим с логином `zhenijoy` и согласованным с владельцем паролем. В коде хранится только SHA-256-хеш пароля. Деморежим сохраняет изменения только в Local Storage браузера и никогда не включается на домене сайта.
